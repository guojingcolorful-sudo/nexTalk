## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 供应商网络 → 计时埋点 | 计时数据可能夹带请求上下文（含签名的 URL、key）进入日志/JSONL |
| 计时报告 → 预算门禁 | 报告本身是可被「善意造假」的（只测热路径即可通过） |
| 计时数据 → 内存 | 长会话的 marks 累积是无界增长面 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `pipeline/budget.rs` 记录与日志（讯飞 URL 带 `authorization=` 查询参数是最易泄露点） | mitigate | 计时记录只存 `Stage`/`segment_id`/ms/`cold`，不存 URL、headers、provider 原始报文；Task 1 的测试断言产出的报告结构中不含 key 材料；02-02 落地供应商客户端时统一「只记 host+path」的脱敏日志（该威胁在 02-02 的 T-02-05 继续追踪） |
