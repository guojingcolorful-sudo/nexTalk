**研究修正（必须折入）：**
1. **讯飞无置信度**：`sc` 恒 0。STT 因子必须是**本地代理**（由 eos 触发时机、片段时长、文本合理性构造），协议上以 `confidenceSource: 'proxy'` 标记，绝不允许把代理值伪装成供应商原值（T-02-09 已登记该威胁）。
2. **AEC crate 无 VAD**：`webrtc-audio-processing` 只提供 AEC3/NS/AGC。分段触发的 VAD 必须自建：**讯飞 `eos` + Deepgram `vad_events` + 本地能量 VAD**（本计划 T3.2 实现本地能量 VAD；02-05 的 T5.1 只做 AEC/NS/AGC，不要再往那里塞 VAD）。
3. **无 Cargo workspace**：`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`，禁止 `--workspace`；CI 第四车道同样。
4. **抢话与 epoch**：`interrupt()` 必须**先自增 epoch 再清空队列**（顺序反了会让正在播放的旧音频把新 epoch 的数据当成自己的续播）。
5. 确定性：所有时间相关逻辑走注入时钟（Phase 1 `TimeSource` 惯例），重试退避与熔断窗口在测试中可快进，不用 `sleep` 做断言。
