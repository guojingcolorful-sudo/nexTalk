**Phase Goal:** The real mic→headphones cascaded streaming translation chain works end-to-end within the 2s budget, with cloned-voice output and honest latency instrumentation gating all downstream phases.

Slice 02-04: 克隆注册 —— 让用户用自己的声音说英文：跨语种可行性探针（先裁决）、真实录音采集、音色训练与本地存储、预置音色回退、试听与重训。

Purpose: 这是「以本人音色讲出地道英文」这条核心价值的最后一环，也是本阶段**唯一未验证的高风险假设**：`.env.example` 声称「ICL 2.0 音色仅支持训练音频同语种合成」，而合成接口提供了 `explicit_language` + `tone_fidelity` 的跨语种路径——文档自相矛盾。盲听实验（D-11）证明了**中文**克隆质量满分，但**英文**输出从未被听过。因此本计划的第一个动作是把这个问题用 15 分钟的实验钉死，而不是先做一周 UI 再发现主供应商不成立。

## Trust Boundaries

| Boundary | Description |

| 录音样本 → 火山训练接口 | 样本必须离开本机一次（训练本身），范围必须最小且可删除 |

| 培训接口响应 → 本地档案 | 供应商返回的 speaker id 与错误码决定状态机走向 |
