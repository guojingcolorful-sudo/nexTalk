<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN client (phone) → axum /ws | Untrusted external input; token gate at upgrade |
| WS wire → H5 renderer | Untrusted messages cross into the DOM |
| LAN HTTP static → phone | H5 payloads served over plain HTTP |
| webview → Rust commands | get_pairing_info/start_session/stop_session exposed to both webviews |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | /ws upgrade | mitigate | 128-bit OsRng token (rand::rngs::OsRng → 32 hex chars) regenerated per process; constant-time string compare not needed (non-secret-bearing compare, random token); 401 on mismatch — implemented in Task 2, covered by cargo test |
| T-01-02 | Tampering | WS payloads → renderers | mitigate | Inbound: serde deny_unknown_fields + 64KB frame cap in client_loop; outbound to H5: isServerEvent narrowing before render (Task 3 + e2e malformed-payload assertion); React default escaping, no dangerouslySetInnerHTML anywhere |
| T-01-03 | Information disclosure | LAN plain-HTTP H5 + WS | accept (locked) | Session-scoped token, Cache-Control: no-store on all ServeDir responses, session-scoped replay (resume only after valid token); stealth/HTTPS out of scope per CONTEXT decisions |
| T-01-04 | Information disclosure | QR token visible on console screen-share | accept | Phase 1 demo scope; stealth (Phase 4) handles screen-share hiding; QR rendered ONLY in the console window (340×680), never the dual-pane |
| T-01-05 | Tampering | cargo installs (axum/tokio/rand/tauri...) | mitigate | crates.io API-verified by research (audit table rows for every crate); tauri pinned 2.11.5 |
| T-01-06 | Elevation of privilege | Tauri command surface in webview | mitigate | capabilities/default.json scopes commands/events per window; H5 has zero privileged surface (pure static page) |
</threat_model>
