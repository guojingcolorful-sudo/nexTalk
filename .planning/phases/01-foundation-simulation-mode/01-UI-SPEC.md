# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: full product UI (4 reference-HTML screens + 6 missing pages) running end-to-end on simulated audio (SimSource). Wired logic for driver/glossary/resume/recording ships in later phases; this contract covers look, feel, states, and copy only.

---

## Design Read & Direction

**Design Read:** "Reading this as: a geek/sci-fi product UI (desktop tool + phone companion screen) for technical interview candidates, with a neobrutalism dark-space language, leaning toward a hand-rolled design-token system per locked spec V1.0 (Space Grotesk, three functional colors, 4px borders, hard offset shadows, dot-matrix texture)."

**Three dials (reasoned from the locked spec, not baseline):**

| Dial | Value | Rationale |
|------|-------|-----------|
| `DESIGN_VARIANCE` | **7** | Neobrutalism: hard-offset shadows, asymmetric bubble tails, colored header bars, guide-line timelines, oversized uppercase micro-labels. Kept below 8-9 because this is functional product UI inside fixed frames (340/860/390px) with a readability mandate during live interviews. |
| `MOTION_INTENSITY` | **4** | Motivated micro-motion only: typewriter rendering (masks LLM latency), button press physics, mic/rec breathing pulse, generating dots. Everything else is static — motion must clarify, never distract, during an interview. All auto-motion honors `prefers-reduced-motion`. |
| `VISUAL_DENSITY` | **5 desktop / 3 mobile** | Desktop: cockpit-like panels with tight 4px rhythm and uppercase micro-labels. Mobile: spec mandates information denoising (沉浸式全屏阅读, no big buttons) — sparse, full-width reading surface, one status capsule. |

**Anti-slop discipline (adapted from taste-skill + user design-quality rules):** each surface must demonstrate at least 4 of: hierarchy via scale contrast; intentional rhythm; depth via hard shadows; typography with character; semantic color; designed hover/focus/active; motion that clarifies flow. Banned: gradient blobs, soft/fuzzy shadows, glassmorphism, 3-equal-card feature rows, uniform radii, safe-gray-on-white, generic template UI. The dot-matrix texture and hard shadows carry the atmosphere; nothing decorative may compromise subtitle legibility.

## Spacing Scale

Base scale is Tailwind's 4px multiplier (spec V1.0 §4.2). All values multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, border offsets, inline padding in micro-badges |
| sm | 8px | Tight element gaps (label-to-bubble, toggle segments) |
| md | 16px | Default padding: page `p-4`, card `p-3`/`p-4` |
| lg | 20px | Page padding `p-5` (spec §4.2), card inner rhythm |
| 2lg | 24px | Bubble-to-bubble gap (`gap-6`), panel padding |
| xl | 32px | Layout gaps between major blocks |
| 2xl | 48px | Section breaks, wizard step separation |
| 3xl | 64px | Page-level spacing (rare in 340/390px frames) |

**Exceptions (documented, spec-locked or grid-normalized):**
- Hard shadows: black 4px offset (spec §5.1), colored 6px offset (reference-HTML baseline), mobile frame 8px. Shadow offsets form their own token family, not the spacing scale.
- Timeline guide-line offsets: normalized to the 4px grid — desktop nodes 24px → line `left-[12px]`, mobile nodes 32px → line `left-[16px]` (reference used 11px/15px; normalization keeps the 4px scale with visual equivalence).
- Touch targets: icon-only buttons in the widget keep a 32px hit area; H5 status capsule icons keep 40px minimum (mobile finger target).

## Typography

Space Grotesk only. Three weights per locked spec §3 (Regular 400 / SemiBold 600 / Bold 700) — deviation from the usual 2-weight contract is spec-locked; Bold is the workhorse of the neobrutalism look.

| Role | Size | Weight | Line Height | Case / Tracking | Usage |
|------|------|--------|-------------|-----------------|-------|
| Panel Title | 18px | 700 | 28px (1.55) | UPPERCASE, `tracking-wider` | Desktop panel titles, brand header, wizard titles |
| Dialogue Body | 15px | 600 | 1.5 | sentence case | Mobile conversation text, strategy card bullets |
| Translation / Notes | 13px | 700 | 1.5 | sentence case | Translation sublines, card annotations, AI-will-speak quotes |
| Label / Status | 12px | 700 | 16px (1.33) | UPPERCASE, `tracking-wider` | Speaker labels, section labels, status pills |
| Mini Badge | 10px | 700 | 14px (1.4) | UPPERCASE | Language toggles, keycap hints, micro-status |

Rules: display type is bold + uppercase + wide tracking, never italic (no italic anywhere in the system — Space Grotesk's character is in its geometry, not slant). Numbers and timestamps use the same font at the same weight. No serif pairing, no second family. Chinese text renders in system default (PingFang SC on macOS/iOS); mixed CN/EN lines keep 1.5 line-height.

## Color

Dark-only by design (locked — it is a tool surface, not a consumer page; the taste-skill dual-mode rule does not apply). One accent per semantic role, locked across every surface (color consistency lock).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#151519` darkerSpace | Window/H5 root background, QR card, neutral blocks |
| Secondary (30%) | `#1E1E24` spaceDark + `#1A1A22` + `#1E293B` slate-800 + `#334155` slate-700 | Panels, sidebars, tabs, interviewer bubbles (+ slate-700 translation subline) |
| Accent (10%) | `#97ce4c` portalGreen + `#fbf061` mortyYellow + `#00b5cc` rickBlue | Functional trio, see reserved-for list |
| Destructive | `#ef4444` red-500 | Destructive actions only: recording indicator, mic-off, delete, disconnect |
| Ink | `#000000` pure black | Borders (4px), hard shadows, text on colored surfaces (spec-locked) |
| Paper | `#FFFFFF` pure white | AI strategy card background, QR tile, highlighted text (spec-locked) |

**Accent reserved for (explicit — never "all interactive elements"):**
- **portalGreen (绿 = 用户/发音/成功):** user's Chinese input bubble, cloned-English output reference, mic active state, user-side CTAs (开始模拟会话), knowledge-base success check, logo X highlight.
- **mortyYellow (黄 = AI/策略):** AI strategy cards, AI timeline strategy node, AI-generating indicator, AI Copilot panel header, resume-ready state.
- **rickBlue (蓝 = 系统/翻译):** interviewer's Chinese translation text, Stealth Mode card, system status (LAN sync, pairing), system info banners.
- **red-500:** recording (REC), mic muted, destructive confirm buttons, disconnect errors. Nothing else.

**Contrast contract (mandatory):** colored surfaces always take black text (portalGreen/rickBlue/mortyYellow/red-500 with `text-black` — all pass AA with black at 5:1-18:1). White text only on dark neutrals (darkerSpace, spaceDark, slate-800, `#1A1A22`, gray-800). Muted labels on dark use gray-400 minimum; tertiary notes gray-500. Never white-on-color or color-on-white for body text.

## Layout & Container Contract

| Container | Size | Radius | Border | Shadow | Content |
|-----------|------|--------|--------|--------|---------|
| Desktop widget | 340×680 | `rounded-3xl` (24px) | 4px black | colored 6px: portalGreen | Brand header (portalGreen), stealth card, sync card, knowledge base rows, bottom action bar |
| Desktop dual-pane | 860×680 | `rounded-3xl` (24px) | 4px black | colored 6px: rickBlue | Header (rickBlue + mic pill), left Live Stream pane (50%), right AI Copilot pane (50%), split by `border-r-4` |
| Mobile frame | 390×844 | `rounded-[40px]` | 4px black | black 8px | Status bar, tabs, chat stream / AI flow, bottom status capsule |

**Dot-matrix texture:** root background of every surface — `background-image: radial-gradient(#4a4a5c 1px, transparent 1px); background-size: 20px 20px;` over the dominant color. Applied ONLY at the root layer (window/page background), never on scrolling containers (performance rule).

**Navigation contract (missing pages reachable from widget):**
1. Widget (340×680) is the hub: top brand header with window controls (min/close), scrollable stack (StealthCard → SyncMobile QR → KnowledgeBase: resume row + glossary row + voice-enrollment row), bottom action bar: 开始模拟会话 (primary) + 扩展视图 (opens dual-pane) + 设置.
2. Setup wizard, voice enrollment, glossary, resume import open as full-width views inside the widget window with a `fa-arrow-left` back affordance in the header.
3. Recording assets + review report open post-session from the widget ("本地资产" section); in Phase 1 they render empty states plus one clearly-labeled mock record (模拟数据) for the demo flow.
4. Dual-pane (860×680) hosts the live simulated session; per-pane headers carry the language toggles.

**Shape consistency lock (documented rule):** device/window frames 24px (mobile 40px); cards 12px (`rounded-xl`); bubbles 12px with one corner zeroed per speaker (interviewer `rounded-tl-none`, user `rounded-tr-none`); timeline icon nodes and status capsule fully round; language toggle segments fully round. Follow this everywhere; no new radii.

## Interaction States

Every component ships the full cycle (taste-skill §4.5), not just the happy path:

- **Loading:** layout-matched skeletons (no generic spinners); stream loading uses TypewriterDots; wizard long steps show step-level progress.
- **Empty:** composed EmptyState per surface with a next step (copy in Copywriting Contract). Subtitles empty ≠ error — it is the pre-session state.
- **Error:** inline ErrorBanner above the affected region with a solution path; transient failures (WS drop) use Toast + auto-reconnect state ("正在重连…").
- **Tactile:** press physics on every button/tile: `hover:translate-y-1 hover:shadow-none`, `active:scale-[0.98]`; toggle segments darken-fill on hover.
- **Disabled:** reduced opacity (50%) + gray borders, no shadow, cursor-not-allowed; primary CTA never disabled mid-session without visible reason.
- **Focus:** 2px solid outline, portalGreen, 2px offset; on green surfaces use black outline; `:focus-visible` only.

## Motion Contract

All motion is compositor-friendly (transform/opacity/text content only). Every animation has a one-sentence motivation:

| Motion | Spec | Motivation |
|--------|------|------------|
| Typewriter (SYNC-05) | Characters appended on interval (30-50ms/char); full text renders instantly under `prefers-reduced-motion`; deterministic for tests | Masks LLM generation latency; makes the stream feel live |
| Button press | `hover:translate-y-1 hover:shadow-none`, `active:scale-[0.98]`, 150ms ease-out | Physical "press" feedback for the hard-shadow aesthetic |
| Mic / REC pulse | `animate-pulse` on red dot and MicStatusPill | Real semantic state: recording is live |
| Generating dots | 3 dots `animate-bounce`, delays 0s/0.1s/0.2s | AI is thinking; matches spec §6 |
| Stealth transition | Opacity → 0 in 0.1s when Cmd+Shift+H pressed (transitional feedback only; real orderOut hiding is Phase 4) | Confirms the keystroke; actual hiding is OS-level in Phase 4 |
| Toast | Slide in 200ms, auto-dismiss 3s | Transient state feedback |
| Auto-scroll | `scrollIntoView({block:'nearest', behavior:'auto'})` on new message only — no scroll-hijacking, no scroll listeners | Keeps newest content visible without jank |

Reduced motion: typewriter renders instantly, pulses go static, toasts appear without slide. No marquees, no parallax, no scroll-triggered animation anywhere in this product.

## Accessibility Contract

- **Contrast:** body ≥ 4.5:1, large/bold ≥ 3:1. Colored surfaces take black text (green/blue/yellow/red all pass with black); muted labels gray-400 minimum on dark; focus ring portalGreen on dark, black on green.
- **ARIA:** subtitle stream `aria-live="polite"`; strategy stream `aria-live="polite"`; StatusCapsule label announces mic state; LanguageToggle segments are `aria-pressed` buttons in a `role="group"`; QR tile has alt text; ConfirmModal traps focus and closes on Esc.
- **Keyboard:** every action reachable; visible focus on `:focus-visible`; no custom cursors.
- **Reduced motion:** per Motion Contract; `prefers-reduced-motion` collapse is mandatory, not optional.

## Compatibility & Performance Contract

- **Safari 15.6 / WKWebView floor (macOS 12.7):** Tailwind v3.4 only (no v4: no `@property`, `color-mix`, `oklch`); esbuild target `safari15`; plain hex tokens in CSS custom properties; no `:has()`; `backdrop-filter` only with `-webkit-` prefix (not currently used); `dvh` allowed (15.4+).
- **Zero CDN (UI-03, Phase 7 verifies):** Space Grotesk WOFF2 (400/600/700, subset, `font-display: swap`, preload 700) and FontAwesome 6 Free (solid subset: fa-bolt, fa-wave-square, fa-mask, fa-qrcode, fa-file-pdf, fa-file-import, fa-check, fa-desktop, fa-closed-captioning, fa-brain, fa-microphone, fa-microphone-slash, fa-user-tie, fa-lightbulb, fa-robot, fa-circle-notch, fa-signal, fa-wifi, fa-battery-full, fa-expand, fa-xmark, fa-minus, fa-arrow-left, fa-trash-can, fa-book, fa-headphones, fa-rotate, fa-satellite-dish) bundled locally.
- **Budgets:** app page JS < 300kb gz, CSS < 50kb gz; no third-party UI libraries.
- **Texture:** dot-matrix background on root surfaces only, never inside scroll containers.
- **Animation:** transform/opacity/text-content only; no scroll listeners; typewriter uses intervals on committed text.
- **Layout stability:** fixed container sizes (340×680 / 860×680 / 390×844) with `overflow-hidden` frames and inner scroll regions; no CLS from dynamic content (bubbles reserve space as they render).
