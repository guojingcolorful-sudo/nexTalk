<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Console webview → Tauri command surface | start_session / stop_session / interrupt / repeat cross from the console window |
| LAN WS client → SessionState | The phone's control messages (language_pref) mutate shared session state |
| Engine → event bus → all renderers | Sim events (trusted origin) flow to desktop webviews + phone renderers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Elevation of privilege | interrupt/repeat/start_session commands | mitigate | capabilities/default.json grants the sim commands to the console window ONLY (extend the 01-02 capabilities file; dual window never receives them); commands no-op unless session_status == generating where applicable |
| T-01-02 | Tampering | control messages → renderers | mitigate | control messages validated at the WS boundary (serde deny_unknown_fields + LanguagePref enum check, 01-02 pattern); renderers still narrow via isServerEvent; seq monotonicity enforced in the engine (dedupe-safe replay) |
| T-01-14 | Spoofing | A LAN client impersonating the session owner sends control spam | accept | Token-gated single-pair session; mode spam has no security impact beyond display; LAN demo scope (documented in RESEARCH Security Domain) |
| T-01-15 | Information disclosure | Vendor experiment framework + future API keys | mitigate | No keys in Phase 1 (README policy, gitignored .env, schema has no secret fields); measure.mjs performs no network calls in Phase 1 (--help only path exercised) |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages in this plan — measure.mjs uses node:https built-ins; all prior installs pre-approved in 01-01 Task 1 blocking-human checkpoint |
</threat_model>
